# Lago Maldito: Criaturas de la noche

Videojuego 2D desarrollado con HTML, CSS, JavaScript y la API Canvas 2D para la asignatura de Graficación.

## Contexto
El juego presenta un lago embrujado donde aparecen murciélagos, fantasmas y ojos espectrales. El usuario debe capturarlos con el ratón mientras observa sus movimientos y las colisiones.

## Objetivo
Aplicar la API Canvas 2D para crear objetos animados, detectar colisiones, manejar eventos del ratón y diseñar una interfaz web interactiva.

## Justificación
El proyecto permite poner en práctica conceptos de animación, coordenadas, movimiento, detección de colisiones, eventos, manejo de recursos y publicación web mediante GitHub Pages.

## Operación
1. Abre `index.html` mediante Live Server.
2. Pulsa **Entrar al lago** o **Comenzar expedición**.
3. Haz clic sobre las criaturas para capturarlas.
4. Usa **Pausar**, **Reiniciar**, **Pulso de luz** y **Activar sonido** según lo necesites.
5. Pulsa `P` para pausar o reanudar.

## Recursos
Coloca los recursos con los nombres y rutas que aparecen en `assets/`. Si una imagen de criatura no está disponible, el juego dibuja una versión alternativa con Canvas. La música se activa después de pulsar el botón de sonido.
